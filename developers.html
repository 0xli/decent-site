Do not install a virtual network just to send a message. Do not rebuild application protocols when an existing service only needs a private address.

PEER API

A peer in a few lines

Identity is created locally and persists in the key file. Bootstrap nodes introduce the peer to the network; a relationship must be accepted before messaging.

import { Peer } from "@decentnetwork/peer";

const peer = await Peer.create({
  keyFile: "./alice/peer.save",
  bootstrapNodes: [{ host: "13.58.208.50", port: 33445, pk: "89vny8MrKdDKs7Uta9RdVmspPjnRMdwMmaiEW27pZ7gh" }],
});
await peer.start();
await peer.joinNetwork();
console.log(peer.address());
