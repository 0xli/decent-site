peer

Peer SDK quickstart

Install the package, create a persistent identity, join the network, then exchange a friend request before sending.

npm install @decentnetwork/peer

import { Peer } from "@decentnetwork/peer";

const peer = await Peer.create({
  keyFile: "./alice/peer.save",
  bootstrapNodes: [{ host: "13.58.208.50", port: 33445, pk: "89vny8MrKdDKs7Uta9RdVmspPjnRMdwMmaiEW27pZ7gh" }],
});
await peer.start();
await peer.joinNetwork();
console.log(peer.address());
agent-mesh

agent-mesh for Claude Code, Codex, and other agents

One peerd daemon owns the durable role identity and warm network connection. Local agents communicate through the mesh CLI and append-only inbox/outbox files; a Stop hook can surface incoming work into interactive sessions.

mesh status
mesh address
mesh request <friend-address>
mesh inbox
mesh send <userid> "task and expected reply"
agentnet

AgentNet / DecentLAN

Use this layer when existing software needs a private address, service ACL, routes, files, or a local desktop console.

sudo npm install -g @decentnetwork/lan
agentnet init
sudo agentnet service install
agentnet ui   # http://localhost:8765
exit-node

Run a regional exit node

An exit is a normal AgentNet node that enables the CONNECT proxy on its private address. Friends can route selected regions or all traffic through it; no public IP or port forwarding is required.

sudo npm install -g @decentnetwork/lan@latest
agentnet init
agentnet proxy enable --port 8888
agentnet proxy allow-host "*"
sudo agentnet service install
agentnet identity show
dora

Dora naming and address registry

Dora runs without root. Nodes friend its address once, then register and resolve userid, name, and private IP mappings over encrypted Peer messages.

npm install -g @decentnetwork/dora
dora --data-dir ~/.dora --verbose
openclaw

OpenClaw Beagle Channel

The local sidecar owns the Beagle network connection; the TypeScript plugin maps Beagle DMs, groups, and media to OpenClaw channel sessions.

git clone https://github.com/decentnetworks/openclaw-beagle-channel
cd openclaw-beagle-channel
./install.sh
