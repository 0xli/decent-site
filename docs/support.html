Decent Network is built by a small team. Here is how to get help while you build on it, and how to reach us if you want us to help with the integration.

Free help: GitHub issues

Open an issue at github.com/decentnetworks/decent.network/issues. It is the public tracker for developer questions about every SDK on this site, including the npm packages whose source repositories are not public yet.

Two SDKs also accept issues in their own repositories:

  • Dora: github.com/0xli/dora/issues
  • agent-mesh: github.com/0xli/decent-agent-mesh/issues

A useful issue contains:

  • the SDK and its exact version (npm ls @decentnetwork/peer, the Gradle dependency, the git commit you built from)
  • the platform: OS and version, Node.js version, Android API level or iOS version, CPU architecture
  • the smallest piece of code that shows the problem, and what you expected to happen
  • the log output. Carrier addresses and userids are public keys and are fine to share; never post the contents of a key file (peer.save, the Carrier data directory, or anything holding a secret key)

We answer issues on a best-effort basis. There is no response-time guarantee for free support.

Technical support and integration help

If you are building a product on Decent Network and want direct help — a review of your integration design, help getting the mobile or native SDKs into your app, or debugging connectivity on your network — write to hi@beagle.chat with:

  • your company or project and what you are building
  • which SDKs and platforms you use
  • what you need help with, and your timeline

Paid technical support plans are being set up. Tell us what you need and we will reply with the options that fit.

Before you ask

  • Start from the SDK reference. Every page has a quickstart that was run against the published version, and says plainly when an integration has not been verified yet.
  • Check whether your two peers are friends. Most "message never arrives" reports come from sending before the friend request was accepted on both sides.
  • Check the version. The Carrier network and the SDKs move quickly; compare yours with the version on the SDK's page.

Security issues

Do not open a public issue for a security vulnerability. Email hi@beagle.chat with "security" in the subject line and we will coordinate a fix and disclosure with you.
