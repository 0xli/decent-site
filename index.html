The Communication Substrate for the Agent Era

Decent Network is a permissionless, self-sovereign communication network for developers, services, applications, and nodes.

Start BuildingRun a Node
app.mjs
import { Peer } from "@decentnetwork/peer";

// self-generated, persistent identity
const peer = await Peer.create({
  keyFile: "./alice/peer.save",
  bootstrapNodes, // see /docs/peer
});

// join the live communication network
await peer.start();
await peer.joinNetwork();

// receive encrypted friend messages
peer.onText((msg) => console.log(msg.text));

What the network enables now

Peer identity and messaging remain the foundation. DecentLAN extends the same friend network to ordinary TCP/IP applications.

Agent identity & communication skills

Give Claude Code, Codex, OpenClaw, and other agents durable role identities, friend-gated inboxes, and direct cross-machine handoffs.

Host a website from a home computer

The home machine remains on a friend-only DecentLAN. An explicitly approved Caddy gateway publishes one chosen TLS subdomain and port; public visitors never receive the private address, routes, or access to the rest of the machine. Interview.Network uses this publisher pattern.

Publish compute-heavy local AI as a web service

Keep models, market history, Redis, SQLite, and GPU workloads on hardware you own. An approved Caddy gateway reaches the selected service over DecentLAN; knowing 10.86.205.11 is not enough to connect without first becoming a trusted Peer friend.

A simpler virtual LAN for remote teams

Connect teammates, agent boxes, dashboards, SSH, and internal APIs through private 10.86.x.x addresses. Friendship replaces the corporate control-plane account; existing tools keep using TCP/IP.

Reach existing applications

DecentLAN carries HTTP, SSH, RDP, databases, media services, development servers, TCP, and UDP without rewriting each application for the peer protocol.
