THE BUILDING BLOCKS

Three installable layers. One relationship model.

Use Peer alone for identity and messaging. Add Dora when a private network needs names. Add DecentLAN when existing applications need IP connectivity.

01FOUNDATION SDK

@decentnetwork/peer

0.1.172

A pure TypeScript/Node.js port of the deployed Carrier protocol. It generates identity locally, joins the DHT, manages friend relationships, establishes encrypted sessions, transfers text and files, and interoperates with Beagle iOS and native Carrier clients.

npm install @decentnetwork/peer
Docs → npm package ↗
  • Node.js 20+, no native runtime dependency
  • DHT + onion discovery, direct UDP, TCP relay
  • Online text, files, and optional Express offline delivery
  • Persistent keystore and friend state
02NAME + ADDRESS SERVICE

@decentnetwork/dora

0.1.16

Dora is DHCP-style naming for AgentNet. A normal Carrier peer assigns a private IP and name, maintains the roster, and answers lookups. Existing nodes keep cached addresses if Dora is temporarily offline.

npm install -g @decentnetwork/dora
Docs → npm package ↗
  • Runs as a normal user — no TUN or root
  • Discover, Offer, Request, Acknowledge flow
  • Userid ↔ name ↔ 10.86.x.x mapping
  • Multiple registries and local fallback supported
03PRIVATE NETWORK RUNTIME

@decentnetwork/lan

0.1.316

DecentLAN, surfaced to users as AgentNet, creates a private virtual network over Peer transport. It adds TUN routing, IPAM, DNS, ACLs, audit, files, a regional proxy, CLI/TUI, and a local desktop console.

npm install -g @decentnetwork/lan
Docs → npm package ↗
  • Private 10.86.x.x addresses across NAT and firewalls
  • Friendship plus service- and time-scoped ACLs
  • SSH, HTTP, RDP, TCP, UDP, and existing software
  • macOS, Linux, and Windows through WSL2
COMPOSITION

How the packages compose

01Your app or agent

Uses messages, files, names, or ordinary network protocols.

02DecentLAN + Dora

Adds private IP routing, policy, service access, names, and address allocation.

03Peer

Owns identity, relationships, discovery, encrypted sessions, relay, and offline delivery.

04Decent infrastructure

Bootstrap, DHT, relay, Express, and optional regional exits keep hard networks reachable.

DDecent.network

Self-sovereign identity and private communication for people, agents, devices, and services.
